
# To-Do List App

A simple interactive To-Do List application built with HTML, CSS, and JavaScript.

## Features

- Add new tasks
- Edit existing tasks
- Remove tasks
- Mark tasks as complete or incomplete
- Prevent empty task entries
- Uses event delegation for dynamically created controls

## Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Event Handling
- Event Delegation

## How It Works

Users can enter a task and add it to the list. Each task includes a checkbox, an Edit button, and a Remove button.

JavaScript dynamically creates and updates the task elements using the DOM. Event delegation is used on the task list to efficiently handle interactions with dynamically created checkboxes and buttons.
